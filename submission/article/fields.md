Shipping and Tracking Support Agent with Strands Decider 2B Model Routing on Amazon Bedrock

Description (max 512 characters):
A conversational shipping support agent that routes simple queries to a fast model and complex ones to a capable model using Strands Decider 2B. Guards every irreversible action (investigations, refunds, replacements, address changes) before it runs. Built with Strands Agents on Amazon Bedrock AgentCore Runtime. Carrier integration supports EasyPost, ShipEngine, and AfterShip via a pluggable provider registry. 124 tests pass; real carrier calls pending API key provisioning.
